Workshop Management System

Werkzatic Automotives

Building a unified, role-based platform that brings intake, repair tracking, and automated PDF invoicing into a single high-contrast workspace. Built for real shop floors where speed is everything.

From Paper to Cloud

The Chaos

Mechanics rely on scattered WhatsApp messages and paper slips. Admins lose track of active repairs, leading to delayed invoices, misplaced parts, and poor customer transparency. The intake process is too slow.

The Fix

A real-time Flutter application backed by Supabase. One centralized ledger for vehicle intake, digital workbenches for technicians, and automated, professional PDF invoicing for the front desk.

The Core Workflow

1. Intake

Capture vehicle info, photos, and initial symptoms.

2. Workbench

Technicians log repairs, parts used, and labor hours.

3. Billing

Admin reviews log and generates branded PDF invoice.

4. Ledger

Permanent history retained for returning customers.

Strict Role-Based Security

Secured by Supabase Row Level Security (RLS) policies. Access is strictly partitioned by user identity.

Technician

  • View assigned intake jobs.
  • Add repair logs and request parts.
  • Cannot view financials or pricing.
  • Cannot generate invoices.

Admin

  • Full overview of all shop operations.
  • Assign jobs to technicians.
  • Manage pricing, inventory, and parts.
  • Generate final PDFs and collect payments.

Built For Real Conditions

Auto-Compressed Media

Intake photos are heavily compressed locally before upload to save bandwidth and storage on Supabase.

1-Tap WhatsApp Sharing

Generated PDF invoices can be securely linked and shared directly to the customer's WhatsApp instantly.

Dynamic PDF Engine

On-device generation of professional, shop-branded invoices requiring zero external API dependencies.
